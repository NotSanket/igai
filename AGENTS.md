# RULES

- Do not change the framework.
- Do not add FastAPI.
- Do not replace Supabase.
- Do not add another database.
- Do not add unnecessary dependencies.
- Do not rewrite working modules without a real reason.
- Do not expose secrets.
- Do not commit `.env.local`.
- Inspect the repository before every phase.
- Work only on the requested phase.
- Do not prematurely implement future phases.
- Run lint after changes.
- Run TypeScript validation where available.
- Run a production build after changes.
- Never proceed while the build is broken.
- Fix errors before adding more functionality.
- Gemini/AI must not be introduced before the deterministic core works.
- Prefer simple, reliable implementations because this is a time-limited hackathon.
